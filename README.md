# Assignment 5

CS341 Software Engineering - Assignment 5

## Description
This Java GUI application reads real numbers from a text file and stores them using a custom linked list. The program calculates and displays the mean and standard deviation of the valid numbers.

## Features
- Selects an input file using JFileChooser
- Stores numbers using a custom linked list
- Calculates the mean
- Calculates the standard deviation
- Handles invalid and empty input
- Displays the results in a Java GUI

## Testing
The program was tested with valid input, invalid input, an empty file, a file containing one value, and a file containing empty lines.
